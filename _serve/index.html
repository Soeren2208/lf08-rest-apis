REST-APIs mit Spring Boot

Lernsituationen LF8 · Fachinformatiker/in – Anwendungsentwicklung

In dieser Reihe entsteht Schritt für Schritt ein REST-Backend mit Spring Boot. Jedes Tutorial besteht aus Arbeitsblättern zum Mitarbeiten und Infoblättern zum Nachschlagen. Die Arbeitsblätter werden der Reihe nach bearbeitet und enden jeweils mit Testfällen zur Selbstprüfung.

Tutorials

01 Personenverwaltung Erste REST-Endpunkte, JPA-Entität, Repository, Statuscodes 02 Gästebuch-Microservice Lombok, ResponseEntity, Paginierung, OpenAPI

Voraussetzungen

  • Java 25 (JDK)
  • Eine Entwicklungsumgebung – IntelliJ IDEA, VS Code oder Eclipse
  • Grundkenntnisse in Java und SQL aus dem ersten Lehrjahr
